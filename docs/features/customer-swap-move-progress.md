# Customer Swap/Move — Implementation Progress

Living document for the Customer Swap/Move feature (Daily Sheets). Full design lives in the approved plan; this file tracks what's actually been done, phase by phase, so later work (possibly a different session) can pick up without re-deriving the design.

Design summary: move one or many customers' `PENDING`/`NOT_AVAILABLE`/`RESCHEDULED` `DailySheetItem`s from their current sheet to a different van's sheet (same date or future date), auto-creating the destination sheet if needed. Mechanism is **in-place mutation** of the existing `DailySheetItem` row (`dailySheetId`/`sequence`/`status`), not copy-and-cancel — decided after tracing every `DailySheetItem` reference in the codebase (see "Why in-place update" in the plan; the decisive finding was `analytics.service.ts`'s `getDeliveries` counting `CANCELLED` as a missed delivery, which copy-and-cancel would have permanently corrupted for moved customers).
